## Full description

Share documents from your phone with links you control.

Docuflash helps you send files, protect access with a password when needed, and
choose when a shared link expires. Create a file request when you need someone
else to send documents back to you.

With Docuflash, you can:

- Upload supported documents and create share links
- Choose public or password-protected access for a link
- Set an expiration for shared links
- Open received document links in the app
- Create file-request links and share them with a QR code
- Review your uploads and manage your account from one place
- Report content that breaks the rules, and block unwanted senders on a file request

Create an account to manage uploads and requests. Password-protected links
require the sender’s password to open. Link availability depends on the
expiration and access settings chosen by the sender.
